# FamilyVault Android

Android is the first FamilyVault client and will be built with Kotlin.

MVP priorities:

- Receive PDFs, images, and documents from Android's native share sheet.
- Let users choose a vault and attach document metadata before upload.
- Upload files directly to cloud storage managed by FamilyVault.
- Open stored files in external Android apps instead of building an internal document viewer.
- Share stored documents to external apps as file attachments through Android's native share sheet.

This directory intentionally starts lightweight. Add Gradle and Android project files when app implementation begins.
